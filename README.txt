# Real Torino PWA v2

Questa versione usa come base l'ultima pagina HTML fornita dall'utente e aggiunge il supporto PWA.

- `index.html` = pagina aggiornata
- `manifest.webmanifest` = installazione PWA
- `sw.js` = funzionamento offline/cache
- `icons/` = icone app

PIN amministratore iniziale: `4826`

Il PIN protegge le modifiche a risultati, marcatori/assist/TW/BL/AN e l'importazione dati. È una protezione lato client: per una sicurezza reale con dati condivisi servirà autenticazione + database.
