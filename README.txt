REAL TORINO PWA – CALENDARIO E TRASFERTE

PUBBLICAZIONE SU GITHUB PAGES
1. Estrai lo ZIP.
2. Carica tutti i file e la cartella "icons" nella root del repository GitHub.
3. In Settings > Pages seleziona Deploy from a branch, branch main, cartella /(root).
4. Apri il sito tramite l'indirizzo HTTPS di GitHub Pages.

INSTALLAZIONE
- Android/Chrome: menu del browser > Installa app / Aggiungi a schermata Home.
- PC/Chrome o Edge: usa l'icona Installa nella barra degli indirizzi o il menu del browser.
- iPhone/iPad: apri il sito in Safari > Condividi > Aggiungi alla schermata Home.

NOTE
- Il file index.html deriva dalla versione HTML caricata, senza riscriverne la grafica o la logica.
- La cache offline comprende la pagina e le risorse PWA; i collegamenti esterni possono richiedere Internet.
- I dati salvati in localStorage rimangono sul singolo dispositivo/browser e non si sincronizzano automaticamente.
- Per installare la PWA il sito deve essere servito in HTTPS (GitHub Pages lo supporta).
